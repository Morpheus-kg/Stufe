# German Trainer

Личное PWA для изучения немецкой лексики к Goethe B2: интервальные повторения по своим карточкам, проверка предложений ИИ, генерация слов, диктант. Интерфейс на русском, контент на немецком. Работает на Node 20 + MySQL.

## Деплой на Railway

Названия пунктов меню Railway могут немного отличаться, суть шагов не меняется.

1. **Репозиторий.** Загрузите проект в GitHub (в корне `package.json`, `Procfile`, `server/`, `public/`, `shared/`, `db/`).
2. **Сервис.** В Railway: *New Project → Deploy from GitHub repo*, выберите репозиторий. Railway определит Node и запустит команду из `Procfile`: `node server/index.js`. Переменную `PORT` задавать не нужно, её подставляет Railway.
3. **MySQL.** В том же проекте: *New → Database → Add MySQL*. Схема создаётся автоматически при первом запуске сервера (миграция выполняется на старте).
4. **Variables.** Откройте сервис приложения → *Variables* и задайте:

   | Переменная | Значение |
   |---|---|
   | `NODE_ENV` | `production` |
   | `TZ_NAME` | `Asia/Bishkek` (или ваш часовой пояс) |
   | `APP_PASSWORD` | ваш пароль для входа |
   | `SESSION_SECRET` | длинная случайная строка, например `openssl rand -hex 32` |
   | `MYSQLHOST`, `MYSQLPORT`, `MYSQLUSER`, `MYSQLPASSWORD`, `MYSQLDATABASE` | ссылки на переменные MySQL-сервиса, например `${{MySQL.MYSQLHOST}}` (имя сервиса в скобках должно совпадать с именем вашей базы в проекте) |
   | `LLM_CHAIN` | порядок провайдеров, по умолчанию `groq,gemini` |
   | `GROQ_KEY`, `GEMINI_KEY` (и/или `OPENROUTER_KEY`) | ключи провайдеров |
   | `GROQ_MODEL_STRONG`, `GROQ_MODEL_FAST`, `GEMINI_MODEL_STRONG`, `GEMINI_MODEL_FAST` (и `OPENROUTER_MODEL_*`) | имена моделей, **проверьте актуальные названия в консоли провайдера** |
   | `AI_DAILY_CAP_CORRECT`, `AI_DAILY_CAP_GENERATE`, `AI_DAILY_CAP_ENRICH` | необязательно, по умолчанию 200 / 40 / 100 |

   Без ключей ИИ приложение работает, недоступны только функции ИИ.
5. **Домен.** *Settings → Networking → Generate Domain*. Адрес вида `https://....up.railway.app` и есть ваше приложение.
6. **Healthcheck (по желанию).** *Settings → Deploy → Healthcheck Path*: `/api/health`.

## Первый вход

1. Откройте домен, введите `APP_PASSWORD`. Сессия хранится 30 дней.
2. *Настройки → Импорт карточек*: выберите JSON с вашими ~300 карточками и нажмите «Импортировать». Повторный импорт безопасен: дубликаты объединяются.
3. *Настройки → Обогащение карточек → «Обогатить новые карточки»*: ИИ заполнит артикли, множественное число, уровень, тему и пропуски. Карточки с расхождением по роду получат пометку «на проверку».
4. Добавьте приложение на главный экран (Chrome: меню → «Установить приложение», Safari: «Поделиться → На экран Домой»).
5. Откройте *Сегодня* и начните сессию.

## Еженедельный экспорт

Раз в неделю: *Настройки → Резервная копия → «Скачать резервную копию»*. Файл `german-trainer-ГГГГ-ММ-ДД.json` содержит карточки, прогресс повторений, журнал ответов, предложения, настройки и статистику. Сохраняйте его вне телефона (облачный диск, почта).

Восстановление: *Настройки → Резервная копия → выбрать файл*. «Объединить» добавляет данные к текущим, «Заменить» полностью заменяет всё и просит подтверждение. Лимит тела запроса на сервере 5 МБ: если файл копии вырос больше, восстановление не пройдёт, а экспорт продолжит работать.

## Обновление приложения

Service worker кэширует статику. После каждого деплоя с изменениями в `public/` или `shared/` **увеличьте `VERSION` в `public/sw.js`**, иначе браузеры будут показывать старые файлы. Приложение подхватит новую версию при следующем запуске.

## Локальный запуск

```bash
npm install
cp .env.example .env   # заполните APP_PASSWORD, SESSION_SECRET, доступ к MySQL
npm start
npm test
```

Откройте `http://localhost:3000` (или порт из `PORT`).

## Если что-то не работает

- **401 на всё:** сессия истекла или неверный `SESSION_SECRET`, войдите заново.
- **«ИИ недоступен»:** проверьте ключи и названия моделей в Variables, а также дневные лимиты (*Настройки → Расход ИИ*).
- **Старый интерфейс после деплоя:** увеличьте `VERSION` в `public/sw.js` и перезагрузите приложение; при необходимости очистите данные сайта.
- **Ответы не уходят на сервер:** смотрите *Настройки → Синхронизация*. Ответы хранятся на устройстве и отправятся при появлении сети.
